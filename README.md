## ⚙️ Open-Source Deterministic Execution Harness (`aethos_harness/`)

This repository ships the self-contained Python reference implementation of the Symbiosis v2.1 execution pipeline:

1. **`aethos_harness/bdp_v1_codec.py` — BDP-v1 Telepathy Wire Codec**
   - Encodes and decodes structured inter-lobe packets (`BDP:v1|INTENT=...|DOM=...|TGT=...|REQ=...|GATE=...`, plus backwards-compatible `KEY:VALUE` decoding).
   - Compresses verbose 244-token engineering prose handoffs down to ~35 tokens (**−85.66%** token overhead).
2. **`aethos_harness/ram_warp_verifier.py` — Volatile RAM-Warp Execution Gate**
   - Executes ephemeral builds inside `/dev/shm` (with automatic `/tmp` fallback) and wipes all temporary files immediately on completion.
   - **C11 Gate (`verify_c11`)**: Compiles with `gcc -std=c11 -O3 -Wall -Wextra -fsanitize=address,undefined` and fails immediately on any ASan/UBSan/LeakSanitizer trace or non-zero exit code.
   - **Python Gate (`verify_python`)**: Validates AST parsing, runs `py_compile`, and executes `pytest` assertions in volatile RAM.
3. **`aethos_harness/zk_receipt.py` — `AETHOS-ZK-V1` Cryptographic Receipts**
   - Generates and verifies deterministic `AETHOS-ZK-V1-<HMAC/SHA256>` attestations binding the canonical **code AST digest**, **compiler exit code**, and **BDP-v1 frame**.

## 🚀 Quickstart

### 1. Clone & Install

```bash
git clone https://github.com/luminiaproductions-ai/aethos-eval-harness.git
cd aethos-eval-harness
pip install -e ".[dev]"
```

### 2. Run the Open-Source Deterministic Execution Harness Tests

```bash
pytest tests/test_harness.py
```

Run the live self-check (BDP-v1 compression + RAM-Warp C11 ASan/UBSan + `AETHOS-ZK-V1` seal & verification):

```bash
python -m aethos_harness
```

### 3. Python API Example

```python
from aethos_harness import encode_bdp, verify_and_seal, verify_receipt

bdp = encode_bdp(
    intent="CODE_VERIFY",
    dom="C11",
    tgt="CT_MEMCMP",
    req=["BOUNDS_SAFE", "CONST_TIME"],
    gate="ASAN_CLEAN",
)

c_code = """
#include <stdint.h>
int main(void) {
    volatile uint8_t diff = 0;
    const uint8_t a[4] = {1,2,3,4}, b[4] = {1,2,3,4};
    for (int i = 0; i < 4; ++i) diff |= (uint8_t)(a[i] ^ b[i]);
    return diff == 0 ? 0 : 1;
}
"""

result, receipt = verify_and_seal(c_code, language="c11", bdp_frame=bdp)
assert result.passed and result.asan_clean
assert verify_receipt(receipt, c_code, result.exit_code, bdp, language="c11")
print(receipt.to_wire())
```

### 4. Run Sovereign Evaluation Suite

```bash
aethos-eval --benchmark frontier-frr
```
